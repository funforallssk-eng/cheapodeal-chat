# Frontend - WhatsApp Clone
Upload all files in this folder to store.cheapodeal.com.au via cPanel File Manager.

Files:
- index.html - WhatsApp Web clone (working)
- manifest.json - Makes it installable PWA
- sw.js - Offline support
- .htaccess - For Apache
- icons

Edit index.html line: const TOKEN_SERVER_URL = "https://your-render-url.onrender.com"
